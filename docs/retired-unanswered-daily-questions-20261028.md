# P0｜每日问卷精简：移出三个长期不填写的量化题目

2026-10-28 · 根据使用者的明确要求 · **只改变今后的问卷显示，不改任何历史数据**

## 本次移出

- 早晨：「晨起体温」（`basal_temperature_c` → `basalTemperatureC`）
- 早晨：「体重」（`weight_kg` → `weightKg`）
- 晚间：「今天大概摄入了多少蛋白质？」（`protein_intake_g` → `proteinIntakeG`）

**没有删除字段映射，也没有改变 `AppBackup`、`DailyRecord.answers`、IndexedDB 数据表或已有导入/导出格式。** 遗留备份中的空值会原样保留；如果某份旧备份含有真实数值，也必须原样保留，不能清洗为 null。历史资料不参与 PR 测试：全部使用虚构示例。

`OPTIONAL_QUESTIONS` 保留为空列表，以免破坏既有导入契约。未来如果用户选择恢复其中一个自测项目，可以另行加入，不需要覆盖旧记录。

## 旧版编辑兼容

既有已完成记录可能把 `weight_kg` 作为 `morningLastQuestionId`。改成新问卷后，此问题已不可见。如果直接使用旧 ID 会出现编辑无法定位当前题目的情况。

新增 `getResumeQuestionId()`：
1. 若旧 ID 仍是当前可见题，保持原有定位；
2. 否则优先寻找当前阶段尚未回答的可见题；
3. 如果已全部回答，就定位到该阶段最后一题，仍允许重新编辑已完成记录。

这个计算只选择显示问题，不改历史状态、完成日期或答案。晨间问题新的终点由实际可见题目计算，不再要求填写已撤下的两个数值项。

## 不误删条件题

例如「吃东西后饥饿感是否缓解」只有前面选择了因饥饿影响睡眠、并且有进食，才会显示。即使某段时期没有有效回答，也不能直接认定是用户主动跳过。所有睡眠、情绪、精力、月经、痤疮、排便、环境事件以及文字备注等题目按原样保留。
